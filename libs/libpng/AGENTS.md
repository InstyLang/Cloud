# AGENTS.md

Package: @ecx/libpng

FFI bindings to libpng 1.6.47, plus the vendored native library. PNG image
decode and encode -- no C compiler or system libpng needed.

## Layout

- `config.toml` - Cloud package configuration (`@ecx/libpng`).
- `src/png.ins` - the bindings module (`import ecx::png`). Generated by
  insbind from `png.h`; do not hand-edit.
- `bin/<target>/` - vendored binaries. Currently
  `bin/x86_64_windows/libpng16.dll` (MSVC `/MT`, statically linked zlib;
  no VC++ runtime or zlib dependency).

## Conventions (from insbind, mirroring windows::*/unix::*)

- Opaque handles are `u64`: `png_structp`, `png_infop`, `png_voidp`-sized
  internals. So are all callbacks (`png_error_ptr`, `png_rw_ptr`,
  `png_flush_ptr`, `png_read_status_ptr`, ...).
- C strings are `text` (const) or `u8*` (mutable). `png_bytep` -> `u8*`,
  `png_bytepp` -> `u8**` (e.g. the row-pointer array for `png_read_image`).
- Constants are zero-argument functions: `png.png_color_type_rgb()`,
  `png.png_interlace_none()`, ...
- Memory-based I/O works fully from Insty: `png_set_read_fn` /
  `png_set_write_fn` with `cast<u64>(&my_fn)` (see the consumer demo);
  stdio-based I/O (`png_init_io` with `FILE*`) is bound but pointless here.

## Error handling: the setjmp caveat (read this)

libpng's default error path is `setjmp`/`longjmp` over C frames, which has
no Insty equivalent. Consequences:

- `png_set_error_fn(png_ptr, user_ptr, error_fn, warning_fn)` captures error
  and warning messages into Insty callbacks -- register it, always.
- A FATAL libpng error (corrupt input, OOM) still ends in `longjmp` to a
  jump buffer nobody set, i.e. process termination. Decoding untrusted or
  possibly-corrupt PNGs therefore needs the planned C shim (a tiny wrapper
  that does setjmp in C and converts failures to return codes); track it as
  `bin/shim` work. Validated in-process input (like the demo) is unaffected.

## Regenerating the bindings

From the libpng source tree (with a configured build dir for pnglibconf.h):

```bash
insbind bind png.h -I . -I <build-dir> -I <insbind>/include \
    --module png --dll libpng16.dll --abi-check > src/png.ins
```

Regenerate when bumping the vendored libpng version (and match
`[project].version`).
